# Yearly Wrapped Statistics & Metrics

## Overview

Yearly Wrapped (`WrappedScreen`) presents a retrospective review of a gardener's annual achievements.

## Aggregated Metrics

- **Total Planted**: Number of habits created in target year.
- **Total Completed**: Number of habits completed in target year.
- **Completion Rate**: `totalCompleted / totalPlanted * 100%`.
- **Total Waterings**: Aggregate log entries recorded in target year.
