# Sanctuary Sorting & Search Filtering

## Overview

Users can search and order their completed plant monuments using search queries and sorting criteria.

## Sorting Options

- **Newest First (`newest`)**: Sorted by `completed_at` timestamp descending.
- **Oldest First (`oldest`)**: Sorted by `completed_at` timestamp ascending.
- **Alphabetical Name (`name`)**: Sorted by habit name A-Z.
